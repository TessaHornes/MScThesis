## MScThesis - DFNs / mesh / DARTS workflow 

This repository contains workflows to create DFNs, make meshes for the DFNs and run flow simulations using DARTSv2.

To make a DFN using GeoDFN and generate a mesh for it use 'DFN+Mesh.py' and run. The use 'Input_dfnmesh.py' and 'Main_dfnmesh.py' for flow simulations. 

To only make the DFN in GeoDFN use 'DFN+Mesh.py' but set 'buildMesh = False'and then use 'Input_dartsmesh.py' and 'Main_dartsmesh.py' for mesh generation and flow simulation.
